# ČSN 73 6110 (2006): local-road design values relevant to the game

**Primary source:** publicly hosted full text, [ČSN 73 6110 PDF](https://unmz.gov.cz/files/normalizace/%C4%8CSN%2073%206110/74506.pdf), downloaded and text-extracted directly. Page numbers below are the **printed page numbers** (PDF pages are generally printed page +2). This is the 2006 edition as hosted; I did not find a separately included Z1/Z2 amendment text in the PDF, so amendment status/current validity is **not verified**. Confidence is high where quoted from the extracted norm; values are transcribed, not independently recalculated.

| Topic | Norm text / value | Clause/table, printed page | Confidence / game interpretation |
|---|---|---|---|
| Local-road scope; public access roads | “Veřejné účelové komunikace se navrhují jako místní komunikace obslužné.” | 8.1.4, p. 29 | **High.** Publicly accessible purpose roads can use group C local-road design. Types with shoulders may instead be designed under ČSN 73 6108 (forest roads) or ČSN 73 6109 (field roads). |
| C design speed | Table 2 gives **30 / 40 / 50 km/h** in normal conditions; **30 km/h** in difficult conditions. Quote: “30 – 40 – 50” and “Obtížné podmínky … 30”. | Table 2, footnote b, p. 20 | **High.** Choose the applicable C value for the road/context; there is no single C speed. In difficult conditions, speed below 40 may result from traffic-calming measures. Parenthesized speeds apply only to transition sections from motorway/expressway. |
| Built-up-area speed | Table 2 is explicitly for local-road functional groups; its C values are not split by built-up vs outside-built-up area. Table 6 examples have C MO types at 30 and 50. | Table 2 p. 20; Table 6 pp. 31–32 | **High.** Do not infer that 50 applies only outside a village: the norm provides no such split in this table. In built-up areas use the selected local-road design speed and context/traffic-calming provisions. |
| D1 speed | No D1 design-speed value is specified in Table 2 (which covers A–C). D1 diagrams are examples of residential-zone layouts, with no speed value shown in the extracted text. | 5.1.10, 8.4.5, pp. 20, 49 | **High that this text gives no D1 speed.** Do not assign C=30 or another design speed to D1 as a norm value without another source. |
| Typical C cross-sections | Table 6 examples: **MO2p 15.5/10.5/30** (two-lane, parking); **MO2a 13.5/10/50** (two-lane, cycle lanes); **MO2p 11/6/30** (two-lane with parking); **MO1p 10.25/6.75/30**, **8.8/5.3/30**, **9/5.5/30** (one lane, parking). First numbers are road-space width / main traffic-space width / design speed. | Table 6, pp. 31–32; symbol definition p. 32; MO1 detail p. 44 | **High.** Good archetypes for village street / local access road. MO1 is an explicitly one-lane C type; use only where one-lane operation is suitable and static parking is resolved. “MO2 8/6/30” was **not** found among the table’s examples; closest listed one-lane/parking examples are above. |
| MO1 / passing places | “Jízdní pás jednopruhový smí být navržen pouze na komunikacích funkční skupiny C”; two-way one-lane roads require passing places. Typical examples require passing places “ve vzájemné vzdálenosti 80–100 m”. | 7.1.2 p. 25; 8.4.4 / figures 16–17 p. 44 | **High.** Clause 8.2.2 also allows 2.50 m lane width only subject to road-space/between-kerbs and meeting-place conditions (p. 33). |
| Lane / between-kerb widths | Normal lane width usually **2.75–3.50 m**; 2.75 m allowed on low-volume C. Two-lane or minor roads can be reduced to **2.25 m** in constrained/existing conditions, with lower permitted speed recommended. One-lane two-way lane 2.50 m only under specified width and passing conditions. | 8.2.2, p. 33 | **High.** Widths are not a universal between-kerbs standard; total width depends on guide strips, parking, sidewalks and safety offsets. Example MO1 traffic-space widths are 5.3–6.75 m, not merely the vehicle lane width. |
| Minimum horizontal radii (with superelevation) | Table 10, radius in metres by crossfall (columns for speeds **50, 40, 30, 20 km/h**): **2.5%: 100, 50, 27, 11**; **2%: 100, 50, 28, 12**; **3%: 95, 50, 27, 11**; **4%: 90, 50, 26, 11**; **5%: 85, 45, 25, 11**; **6%: 85, 45, 25, 10**. Quote: “Nejmenší dovolené poloměry … jsou dány v tabulce 10.” | 9.4.4, Table 10, p. 51 | **High.** Table minima are expressly a function of crossfall. 2% is allowed only in justified reconstruction cases; 2.5% is the usual basic crossfall (9.5.1, p. 52). Use the row corresponding to actual crossfall, not a generic “exceptional” radius. The norm table extends to 6%, no separate more-extreme row. |
| Radius with ordinary roof-shaped 2.5% crossfall | Same as 2.5% row above. A 2.5% roof crossfall is the usual basic crossfall in a straight. For curves, normal design uses superelevation at radii below Table 11 threshold. | 9.5.1, Table 10, Table 11, pp. 51–52 | **High.** At 30 km/h, threshold below which superelevation is required is R=250 m; at 40: 450 m; 50: 700 m. “Without superelevation” is thus a separate and much larger-radius condition, not the 2.5% minimum-radius row. |
| Radius without superelevation | Table 11 minima (30/40/50 km/h): **250 / 450 / 700 m**. Below these radii, superelevation is prescribed; “Nejmenší dovolená hodnota dostředného sklonu” equals basic crossfall (normally 2.5%). | 9.5.3, Table 11, p. 52 | **High.** Table 11 says when a centripetal crossfall must be provided, not the smallest radius at which a road can exist. |
| Transition curves | 9.4.1 permits circular-with-transition, simple circular, compound, or transition-only curves. 9.4.3 restricts *simple circular* curves only for groups A/B (R≥1600 m, or transition shift ΔR≤0.25 m). 9.4.5 says transition “zpravidla” clothoid; 9.4.6 gives ordinary length **L = vn** when rotating about road axis, or **L = 1.5 vn** about edge/guide strip (vn in km/h, L in m). | 9.4.1, 9.4.3–9.4.6, pp. 50–51 | **High.** The A/B-only restriction means the norm does not require transitions on C/D1 at the small radii used there; a simple circle is an available form. No explicit minimum transition length stated in these clauses. If a transition is used, the formula applies. |
| Vertical curve minimum radii | **Crest (Rv), stopping sight:** at 50/40/30/20 km/h = **1,000 / 450 / 200 / 100 m**. **Sag (Ru), stopping sight and overtaking:** **700 / 350 / 180 / 110 m**. | Tables 13–14, p. 54 | **High.** The tables are keyed by design speed; no D1-specific speed is supplied. Crest radii for overtaking are only given at 70 and 60 km/h (25,000 / 20,000 m), not relevant to normal C designs. All local roads must ensure stopping sight distance (9.7.3, p. 53). |
| Maximum longitudinal grade, C | Table 12: **9% normal**, **12% justified**, **15% extraordinary, section up to 50 m**. The 15% row note also says “15% ve skupině C v obytné zástavbě”. | 9.6.3, Table 12, p. 53 | **High.** Your proposed 9/12/15% values and ≤50 m limit are confirmed. Minimum grade generally 0.5% (9.6.2). |
| Maximum longitudinal grade, D1 | Table 12 lists D1 “obytné a pěší zóny”: **5% normal; 8.33% justified**. Clause 9.6.4 separately states D1 “nemá … přestoupit” **8.33%**, but in justified existing built-up conditions may reach **12.5%**. | 9.6.3 Table 12 and 9.6.4, p. 53 | **High.** Distinguish the general table from the explicit existing-development exception. |
| Reverse curves / straight length | “Mezi protisměrné oblouky s přechodnicemi není nutné vkládat přímou.” For circular curves, straight lengths are recommended for superelevation runoff and possible widening. No straight is inserted between two same-direction curves; they are replaced by one smooth curve on A if visible throughout and shorter than Table 9 minima. Table 9 minima at 50/40/30: **140/120/90 m**. | 9.3.1, Table 9, p. 51 | **High.** Table 9 addresses same-direction arcs; it is not a minimum straight between reverse curves. |
| Curve widening at low radii | At C reconstruction, each lane in curves is widened at least per Table 5, with swept-path verification. At radius 100 m: lane widths 2.50/2.25 → **+0.80 m**; 3.00/2.75 → **+0.50 m**; 3.25/3.50 → no listed value. At 50 m: **+1.30 / +0.80 / +0.30 m** respectively. | 7.1.3, Table 5, p. 25 | **High.** Table 5 applies to groups B/C on reconstruction; do not apply blindly to new-build C or D1. |

**Useful exact short quotes:** “Veřejné účelové komunikace se navrhují jako místní komunikace obslužné” (8.1.4); “Největší podélný sklon místních komunikací nesmí přestoupit hodnoty uvedené v tabulce 12” (9.6.3); and “Mezi protisměrné oblouky s přechodnicemi není nutné vkládat přímou” (9.3.1).
